Sobre o Projeto
Este projeto foi desenvolvido como parte da Feira de Ciências com o objetivo de criar uma plataforma digital interativa para divulgar os cursos técnicos oferecidos pelo colégio.

O site serve como um guia completo para estudantes do ensino fundamental, médio e visitantes que desejam conhecer as opções de formação profissional disponíveis na instituição. A plataforma apresenta informações detalhadas sobre cada curso, auxiliando os estudantes na tomada de decisão sobre seu futuro profissional.

Funcionalidades Principais
Apresentação Institucional: Seção inicial com destaque para a importância do ensino técnico e os diferenciais do colégio.

Catálogo de Cursos: Listagem organizada de todas as formações técnicas oferecidas, como Desenvolvimento de Sistemas, Administração, Eletrotécnica e Enfermagem.

Filtros Interativos: Sistema em JavaScript que permite filtrar os cursos por área de conhecimento, divididos entre Tecnologia, Saúde, Gestão e Indústria.

Janelas Modais de Detalhes: Recursos acionados por cliques para exibir informações aprofundadas sobre cada curso sem a necessidade de sair da página principal:

Grade curricular básica.

Duração do curso e período de funcionamento (matutino, vespertino ou noturno).

Mercado de trabalho e perspectivas de atuação profissional.

Formulário de Contato: Seção para que os interessados possam enviar dúvidas ou solicitar orientações sobre o processo seletivo.

Tecnologias Utilizadas
O projeto foi construído utilizando tecnologias web fundamentais, garantindo alta performance e facilidade de manutenção sem o uso de frameworks externos:

HTML5: Utilizado para a estruturação semântica de todo o conteúdo da página, garantindo acessibilidade e organização lógica das informações.

CSS3: Responsável pela identidade visual, estilização dos componentes, paleta de cores institucional e design responsivo (utilizando Flexbox e CSS Grid para adaptação em computadores, tablets e smartphones).

JavaScript (ES6+): Responsável pela interatividade dinâmica do site, incluindo a manipulação do DOM para abertura de modais, filtragem em tempo real e validação de formulários.
